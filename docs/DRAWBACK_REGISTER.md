# Drawback register

Every gap raised by the three independent reviews, and by the "make it real" brief, with where it stands **today**. Statuses are conservative.

- **DONE (verified):** fixed, and a test or measurement in this repository would fail if it regressed.
- **DONE (not verifiable here):** built, but it cannot be proved without something this repository does not have (a key, a native speaker, a regulator, real users).
- **PARTIAL:** reduced, with a stated remaining gap.
- **NOT DONE:** left, usually on purpose.

The list is built from the reviewers' written points as they were passed to the build. If your own list has an item that is not here, it should be added, not assumed fixed.
